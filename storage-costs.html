Cost of listing files in a snapshot

Restic can list a snapshot without downloading the backed-up file contents:

uv run restic-backups generic restic run --backup <job-id> ls <snapshot-id>

The command downloads repository indexes, snapshot records, directory trees, and other required metadata. Commands such as restore and dump download file data. Restic’s local cache can reduce metadata reads on subsequent commands. Set cache-dir on a restic-repositories entry to give each repository a stable, separate cache location; see Configuration.

Prime that cache with repository metadata before browsing snapshots:

uv run restic-backups generic repository prime-cache <repository-id>

This runs restic check --with-cache; it does not download backed-up file data.

AWS currently includes the first 100 GB per month of internet data transfer out, aggregated across AWS services and regions. Backblaze charges $0.01/GB only for egress beyond its free allowance. Exact costs depend on the repository’s metadata size, object count, local cache, and other usage during the billing month.

Important differences

AWS and Backblaze prices are metered object-storage charges. Google Drive and OneDrive prices are fixed consumer subscription tiers that include other services. This project supports S3-compatible and local filesystem storage; Google Drive and OneDrive cannot be selected as storage backends.

Both Glacier classes have a 90-day minimum storage duration. Instant Retrieval is immediately readable but has a 128 KB minimum billable object size and separate data-retrieval charges. Flexible Retrieval first requires an archive restore: expedited retrieval typically takes 1–5 minutes, standard takes 3–5 hours, and bulk takes 5–12 hours. It also bills 40 KB of metadata per object, which is not included in the estimates above.

For Flexible Retrieval, configure a restore policy and set ALLOW_ARCHIVE_RETRIEVAL=1 when running retrieval-related commands. S3 Standard and B2 do not require an archive restore before normal access. Backblaze includes free egress up to three times average monthly storage; AWS transfer and request charges vary by usage and region.
